Notes on the plan:

- Row order is dependency order, backward only. An empty Annotation cell is parallel-safe once the rows above it have landed.
- **No server surface, by contract.** `07-write-path.md` line 90: "No share endpoint exists: decision 30's WhatsApp card is client-only composition." Every slice above is client plus builder work. A slice that provisions a backend for sharing violates the accepted design.
- **Byte discipline.** Keystone slice-08's CI gate enforces the ceilings of `application-architecture.md` §5: 14 KB gz per document, 100 KB per route first visit. Estimated adds: the `wa.me` anchor ~120 B gz on the home document (slice-01), the OG meta block ~180 B gz per document head (slice-03), the share island 1.0 KB gz deferred and already booked as budget line item 3 (slices 02 and 05), the OG image zero page bytes because only WhatsApp's crawler fetches it (slice-04). Every byte-adding slice ships under the gate; a regression fails CI naming route, measured bytes and ceiling.
- **Domain swap path.** `site` in `astro.config.mjs` is the single owner of the absolute host. The share template `{url}`, `og:url` and the canonical all derive from it. Registering surfsuppanama.com later is one config edit, one rebuild, one republish. Until then every paste carries the CloudFront hostname; that cost was accepted with the decision (HANDOFF §10).
- **UI classification.** Every slice is user-visible (slice-04's page-facing observable is the preview card). At each slice's DISTILL open, load `nw-ui-quality-mandates`, carry the U1-U7 requirement rows (R20 to R26 in `distill/requirement-checklist.md`) with executable checks through the built surface, and seal the slice charter's U8 observation for Vera. No later polish pass exists.
- **P7 field integrity, learned the hard way.** HANDOFF §10 records that `data/published-surface.json` shipped with the share-relevant optional fields missing on 19 of 20 calls while every gate stayed green. The share text and the OG card read the same five fields (`score_q`, `size_band`, `size_range_m`, `wind_state`, `conf_level`). Slice-01 DISTILL owes an explicit check that the fields the template reads are populated for the shared spot, and the declared degrade paths (P7 row, §7) are exercised, never assumed.
